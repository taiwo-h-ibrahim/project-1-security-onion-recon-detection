# Evidence Directory

This folder is for sanitized evidence that supports the findings documented in the root README.

## Suggested artifacts

Add only artifacts that were actually captured during the lab:

- Lab topology screenshot, with irrelevant host or account details removed.
- Security Onion or Suricata alert evidence showing the relevant event.
- A packet-analysis screenshot or short sanitized event excerpt, if available.
- A short investigation timeline only if timestamps can be confirmed from the original evidence.

## Evidence handling

- Review screenshots before publishing; obscure credentials, tokens, public IPs that should not be disclosed, and unrelated personal information.
- Do not upload unreviewed PCAPs. Captures can contain unrelated traffic or sensitive data.
- Explain what each artifact proves and what it does not prove.
- Keep alert telemetry and packet-capture findings clearly distinguished.

No evidence files have been added to this folder yet. This note is an index and checklist, not evidence of a detection by itself.
